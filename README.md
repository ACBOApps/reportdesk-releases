# ACBO - ReportDesk — εκδόσεις

Ενημέρωση πελατών λογιστικού γραφείου με εκτίμηση ΦΠΑ από τα ηλεκτρονικά βιβλία της ΑΑΔΕ (myDATA). Τρέχει στον δικό σας server, μόνο στο τοπικό δίκτυο.

**Λήψη:** [Releases](https://github.com/ACBOApps/reportdesk-releases/releases/latest) → `ReportDesk-Setup-x.y.z.exe`.

- Οι εγκαταστάσεις ελέγχουν μόνες τους για νέα έκδοση (Ρυθμίσεις → Server - Ενημέρωση).
- Κάθε έκδοση φέρει ψηφιακή υπογραφή (Ed25519) και γίνεται δεκτή από την εφαρμογή μόνο αν η υπογραφή είναι έγκυρη.
